Sanjay watched the War of Kurukshetra and narrated it to the blind king, Dhritarashtra. Now he has the internet and your network is the battlefield. Web, mobile, binaries, malware - divine sight (divya drishti) for everything you can't see.

## Download

Grab the latest build from the [releases page](https://github.com/ayushmanchhabra/sanjay/releases/latest), picking the file for your platform:

| Platform              | File                      | Install                                     |
| --------------------- | ------------------------- | ------------------------------------------- |
| Linux (Intel/AMD)     | `sanjay-x86_64.AppImage`  | `chmod +x` the file, then run it            |
| Linux (ARM)           | `sanjay-aarch64.AppImage` | `chmod +x` the file, then run it            |
| Windows               | `sanjay-x64-Setup.exe`    | Run the installer                           |
| macOS (Apple Silicon) | `sanjay-arm64.dmg`        | Open the DMG, drag Sanjay into Applications |
| macOS (Intel)         | `sanjay-x64.dmg`          | Open the DMG, drag Sanjay into Applications |

## Vision

- Android testing setup
- Network testing setup
- VPN integration - IP rotation, etc
- Use LOLBins to automatically do things like subdomain enumeration, DNS record analysis, IPDR analysis, TLS cert analysis, directory listing, 403 bypass, etc.
